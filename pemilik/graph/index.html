Jaringan grup bisnis, perusahaan perantara, dan emiten tercatat yang mereka kendalikan, termasuk rantai berlapis. Geser node untuk menjelajah, klik node untuk detail.

Lingkaran besar = grup, lingkaran sedang = perusahaan perantara, lingkaran kecil = emiten (warna mengikuti grupnya). Angka di garis = persentase kepemilikan bila tersedia. Data dari keterbukaan publik, dapat berubah.
